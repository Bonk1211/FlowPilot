# Coupon photo inspection fixtures

These three AI-generated photos are controlled illustrations for the hackathon demo. They are not measured factory data. The uniform coupon is calibration image B; missing coating and coarse deposits are local edits of B. A separate normal image A alone built the reference bank and is retained in the standalone experiment. Related B images never entered the reference bank.

The fixed ResNet18 layer2/layer3 PatchCore-style prototype uses the central ROI (20%,20%,80%,80%), bicubic resize to 224px, ImageNet RGB normalization, 3×3 average patch aggregation and Euclidean nearest-neighbor distances to 78 normal patches. The maximum patch distance is the raw image score. It is not the canonical paper implementation, a probability, a root cause, or a coating coverage measurement.

The demo operating cutoff was fixed as 1.25 × calibration normal B's score before running missing-coating inference. Results: normal 1.5048033; cutoff 1.8810041; missing 3.2035763; coarse 3.8990941. Heatmap maxima landed in both edited regions. B is now a calibration reference, not an independent normal test. One pair per defect does not establish accuracy or robustness. The expected input is a square, top-down coupon closeup with matching framing; arbitrary machine photographs are outside this detector's scope. Only the central ROI is evaluated. A `within_reference` result does not prove the equipment is repaired.

`manifest.json` pins preprocessing, threshold, bank and backbone hashes. `memory-bank.npz` is the compact reference bank. Official ImageNet ResNet18 weights are fetched once by `npm run vision:setup` into ignored `.cache/vision/model/`, never during API inference. Source: https://download.pytorch.org/models/resnet18-f37072fd.pth. Upstream architecture: https://github.com/pytorch/vision. Algorithm inspiration: https://github.com/amazon-science/patchcore-inspection.

The missing-coating image was generated using the built-in image tool with normal B as the edit target. Prompt: change only a local flat missing-coating region centered at x=.61,y=.42, roughly x=.51–.71/y=.32–.52; show bare dark substrate with stippled edges; preserve outer coupon, original coated-square boundaries, camera, background, lighting and surrounding texture; no hole, labels, heatmaps or extra objects. Image generation can still alter surrounding texture; this is not a perfectly controlled physical experiment.
